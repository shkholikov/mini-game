# «Наш дом»

Детская игра-стройка на HTML5 для трёх детей (1, 3 и 5 лет), которые по очереди строят копию своего настоящего двухэтажного дома на одном планшете.

**Полный дизайн-документ: `docs/GAME_SPEC.md`. Прочитай его перед любой работой над фичами и следуй ему.** Промпты по шагам плана: `docs/PROMPTS.md`.

## Стек

- Phaser 4 + TypeScript 6 (strict) + Vite, пакетный менеджер **pnpm**. Это Phaser **4**: не используй API из Phaser 3 по памяти — сверяйся со скиллами `.claude/skills/phaser-*` (скопированы из `node_modules/phaser/skills`) или с `node_modules/phaser/types/phaser.d.ts`
- `vite-plugin-pwa` для установки на планшет и офлайна
- Vitest для логики, Playwright для smoke-тестов
- Без бэкенда: состояние хранится в `localStorage`
- Целевое устройство: **Android-планшет (Chrome)**; iPad (Safari) — вторичный

## Команды

```bash
pnpm dev                     # локальный сервер; с планшета: pnpm dev --host и открыть по IP в той же Wi-Fi
pnpm build                   # tsc + продакшн-билд в dist/
pnpm test                    # vitest (все)
pnpm vitest run tests/TurnManager.test.ts   # один файл
pnpm vitest run -t "имя теста"              # один тест по имени
pnpm test:e2e                # playwright smoke (сам собирает билд и поднимает preview на :4173)
pnpm lint
```

## Архитектура (общая картина)

Общие константы (`GAME_WIDTH`, `GAME_HEIGHT`, `SAFE_AREA`) — в `src/config/game.ts`. Защита от жестов (зум, контекстное меню, «назад») — `src/systems/TouchGuards.ts` + CSS в `src/style.css`; портретная ориентация показывает анимацию «поверни планшет» без текста.

Поток сцен: `BootScene` → `PlayerSelectScene` → `HouseScene` (камера на деталь) → `TaskScene` → `CelebrationScene` → снова `PlayerSelectScene`. `ParentScene` открывается только через родительский замок.

- **Контент — это данные.** Этапы и шаги — `StepDef` в `src/config/stages.ts`. Текущий шаг = первый шаг, которого нет в `SaveState.completedSteps`. `TaskScene` берёт `step.byLevel[player.level]` и по `TaskDef.type` запускает движок из `src/tasks/`. Новые этапы — только правка `stages.ts`; новый код нужен только для нового _типа_ задания.
- **Дом рисуется из состояния.** `HouseScene` строит дом по `house.config.json` и показывает детали (`StepDef.housePart`) для всех шагов из `completedSteps`. Дом не хранит своё состояние отдельно.
- **Системы** (`src/systems/`) не зависят от Phaser там, где возможно, чтобы их можно было тестировать в Vitest: `TurnManager` (очередь), `SaveManager` (localStorage + миграции по `version`), `HintManager` (ошибки → подсказка), `AudioManager` (фразы по id, склейка с именем).
- **Очередь:** пульсирует ребёнок с наименьшим числом ходов в текущем круге (при равенстве — по порядку в `players.json`). Если пульсирующего пропустили и сыграл другой, пропущенный остаётся следующим.
- **Голос:** фразы по id из `assets/audio/phrases.csv`; имя ребёнка — отдельный файл. Фразы, зависящие от рода (положил/положила), имеют два варианта и выбираются по `player.gender`.

## Соглашения

- Идентификаторы в коде на английском; **весь текст и голос для пользователя на русском**, строки только в `src/i18n/ru.ts`.
- Каждый `StepDef` обязан содержать задания для всех трёх уровней: `toddler`, `preschool`, `older`.
- Конфигурация дома и игроков только из `src/config/house.config.json` и `players.json`; никаких захардкоженных имён и цветов в сценах.
- Ориентация только landscape, `Scale.FIT`, базовое разрешение 1600×900. Всё интерактивное держать в безопасной зоне, видимой и при 4:3 (центральные 1200×900); небо и земля заполняют края.
- Маленькие коммиты: одна фича или пункт плана из GAME_SPEC §9 за раз. После завершения пункта отметь чекбокс в GAME_SPEC.

## Жёсткие правила (никогда не нарушать)

1. Нет состояний проигрыша, красных крестиков, слова «неправильно». Ошибка → мягкий возврат + подсказка (см. `HintManager`: 2 ошибки → подсветка, 3 → автопомощь). Для `toddler` подсказки не нужны — у него ошибок не бывает.
2. Нет таймеров в заданиях.
3. Играть можно без чтения: каждая инструкция озвучена.
4. Минимальный размер цели касания: toddler 120 px, preschool 96 px, older 72 px (в координатах базового разрешения).
5. Для `toddler` любое касание в зоне задания засчитывается.
6. Никаких сетевых запросов во время игры, рекламы, внешних ссылок, аналитики и трекеров. Данные детей не покидают устройство.
7. Нет звука для ассета → пропустить и `console.warn`, никогда не падать.
8. Запрещены pinch-zoom, выделение текста, контекстное меню, свайп «назад».
9. Родительские настройки только за родительским замком (удержание 3 с + пример на сложение).
10. Весь билд меньше 15 МБ.

## Проверка перед завершением задачи

- `pnpm build` проходит без ошибок TypeScript.
- `pnpm test` зелёный; для изменённой логики (очередь, сохранение, подсказки) есть тест.
- Новое задание проверено на всех трёх уровнях.
- Для визуальных изменений: проверить при 1024×768, 1280×800 и 2560×1600.

## Сохранение

`SaveState` имеет поле `version`. При изменении структуры добавь миграцию в `SaveManager`; никогда не стирай прогресс детей молча. При старте вызывать `navigator.storage.persist()`.
