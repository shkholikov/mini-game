# «Наш дом» — игра-стройка для трёх детей

> Дизайн-документ (ТЗ). Источник правды для всей разработки.
> Claude Code: читай этот файл перед любой работой над фичами.

---

## 1. Суть игры

Одна общая игра на одном планшете. Трое детей (1, 3 и 5 лет) **по очереди** строят копию **своего настоящего двухэтажного дома**: от пустого участка до обставленных комнат и сада.

- Каждый ход — одно короткое задание (30–90 секунд).
- Сложность задания подстраивается под возраст того, кто сейчас играет.
- Дом общий: всё, что сделал каждый, остаётся в доме навсегда.
- Финал — «новоселье», после него открывается свободный режим «Живой дом».

**Почему это работает:** дети узнают свой дом, видят свой вклад и учатся без ощущения урока: счёт, цвета, формы, порядок действий, профессии, «что в какой комнате».

## 2. Игроки и возрастные уровни

| Уровень (код) | Возраст | Что ребёнок умеет                           | Тип заданий                                              | Мин. размер цели |
| ------------- | ------- | ------------------------------------------- | -------------------------------------------------------- | ---------------- |
| `toddler`     | 1 год   | Тапает ладошкой, неточно                    | «Нажми и случится чудо»: любое касание засчитывается     | 120 px           |
| `preschool`   | 3 года  | Тянет один предмет, различает цвета и формы | Выбор из 2–3, перетащить в подсвеченное место            | 96 px            |
| `older`       | 5 лет   | Считает до 10, понимает порядок и логику    | Выбор из 3–4, посчитать, продолжить узор, рассортировать | 72 px            |

## 3. Очередь ходов

**Экран «Кто строит?»**

- Три большие круглые кнопки с лицом и именем каждого ребёнка.
- Следующий по кругу мягко пульсирует, но нажать можно любого: спор решает родитель, а не игра.
- «Следующий» = ребёнок с наименьшим числом ходов в текущем круге (при равенстве — по порядку в `players.json`). Если его пропустили и сыграл другой, пропущенный остаётся следующим.
- Голос: «Сейчас строит Амир!»
- Под каждым аватаром кирпичики-звёздочки, сколько ходов сделал ребёнок. Все видят свой вклад.

**Цикл хода**

1. Выбор игрока → 2. Камера показывает, что сейчас строим → 3. Задание по уровню игрока → 4. Праздник (конфетти, звук, голос «Ура! Амир положил крышу!») → 5. Деталь появляется в доме → 6. Возврат к выбору игрока.

**Честность:** каждый этап разбит на столько шагов, чтобы за круг каждому досталось хотя бы одно действие (обычно 3–6 шагов на этап).

## 4. Мир и вид

- **Вид сбоку, дом в разрезе**, как кукольный домик: видны оба этажа и все комнаты.
- Участок: забор, ворота, двор, небо (день/ночь в свободном режиме).
- **Только горизонтальная ориентация.**
- Стиль: плоская векторная графика, мягкие цвета, крупные формы, без мелких деталей.

**Персонализация: дом максимально похож на настоящий.** Всё описывается в `src/config/house.config.json`:

```json
{
  "floors": [
    { "level": 1, "rooms": ["kitchen", "living", "bathroom", "hall"] },
    { "level": 2, "rooms": ["bedroom_parents", "kids_room", "bathroom2"] }
  ],
  "facadeColor": "#F2E6D0",
  "roofColor": "#8B3A2F",
  "roofType": "gable",
  "gateColor": "#4A4A4A",
  "windowsPerFloor": [3, 3],
  "yard": ["tree_apple", "tree_apricot", "garden_bed", "swing", "cat"]
}
```

Заполняется по фото настоящего дома (см. раздел 11).

## 5. Этапы стройки

Порядок этапов сам по себе обучающий: сначала фундамент, потом стены, потом крыша.

| #   | Этап                  | `toddler` (1 год)                                               | `preschool` (3 года)                                    | `older` (5 лет)                                                        | Чему учит           |
| --- | --------------------- | --------------------------------------------------------------- | ------------------------------------------------------- | ---------------------------------------------------------------------- | ------------------- |
| 1   | Участок               | Тап по камню, он улетает                                        | Перетащить камни в тачку                                | Убрать ровно 5 камней, считая вслух                                    | Счёт, порядок       |
| 2   | Фундамент             | Тап, бетономешалка льёт бетон                                   | Найти бетономешалку среди 3 машин                       | Выбрать нужную машину из 4 (экскаватор, кран, самосвал, бетономешалка) | Техника и профессии |
| 3   | Стены 1 этажа         | Тап, кирпич ложится                                             | Класть кирпичи одного цвета                             | Продолжить узор (красный-жёлтый-красный-…)                             | Цвета, узоры        |
| 4   | Перекрытие и лестница | Тап, кран опускает плиту                                        | Перетащить ступеньки по порядку, от маленькой к большой | Собрать лестницу из 5 ступенек по счёту                                | Размер, счёт        |
| 5   | Стены 2 этажа         | Тап, кирпич ложится                                             | Цвет как у настоящего дома (выбор из 3)                 | Узор сложнее (3 цвета)                                                 | Цвета, внимание     |
| 6   | Крыша                 | Тап, крыша опускается краном                                    | Выбрать крышу нужного цвета                             | Выбрать правильную форму крыши (треугольник)                           | Формы               |
| 7   | Окна и двери          | Тап, окно появляется со звоном                                  | Вставить окно нужной формы                              | Посчитать окна на этаже и вставить все                                 | Формы, счёт         |
| 8   | Покраска фасада       | Тап, «плюх» краской                                             | Покрасить цветом по образцу                             | Смешать цвета (синий + жёлтый = зелёный)                               | Смешивание цветов   |
| 9   | Свет                  | Тап, лампочка загорается                                        | Соединить лампу с выключателем                          | Включить свет только в тёмных комнатах и посчитать их                  | Причина и следствие |
| 10  | Комнаты               | Тап, мебель появляется со звуком                                | Найти кровать / стол / ванну                            | Куда поставить холодильник? Сортировка мебели по комнатам              | Комнаты, логика     |
| 11  | Двор и сад            | Тап, прилетает птица / бабочка                                  | Полить цветок, он растёт                                | Посадить 3 дерева и 4 цветка                                           | Природа, счёт       |
| 12  | Новоселье             | Все трое героев заходят в дом, общий праздник и «семейное фото» | —                                                       | —                                                                      | Командная работа    |

**После финала: свободный режим «Живой дом»**

- День и ночь: включать и выключать свет.
- Кормить кошку, поливать сад, собирать урожай.
- У каждого ребёнка своя комната (или угол) на 2 этаже, которую он украшает сам.
- Переставлять мебель.

## 6. Правила UX для маленьких (жёсткие, нарушать нельзя)

1. **Нет проигрыша.** Нет красных крестиков и слова «неправильно».
   - Ошибка: предмет мягко возвращается, голос говорит «Попробуй ещё!».
   - После 2 ошибок правильный вариант подсвечивается.
   - После 3 ошибок игра помогает сама (предмет «доезжает» на место).
2. **Нет таймеров** в заданиях.
3. **Не нужно читать.** Всё голосом и картинками. Текст только для родителей.
4. **Нет рекламы, покупок, внешних ссылок, чатов, аналитики.** Данные детей не покидают планшет.
5. **Родительский замок:** настройки и сброс открываются удержанием кнопки в углу 3 секунды, плюс пример на сложение до 20 (5-летний не пройдёт случайно).
6. **Лимит времени (опционально):** после N ходов голос говорит «Строители устали. Отдохнём до завтра?», настраивает родитель.
7. **Звук:** голос и мягкие эффекты, без резких звуков; музыку можно выключить отдельно.
8. **Защита от случайных выходов:** запретить pinch-zoom, выделение текста, контекстное меню по долгому нажатию, свайп «назад».
9. **Для `toddler` любое касание в зоне задания засчитывается**: малыш не может застрять. Поэтому правило подсказок (п. 1) действует только для `preschool` и `older`.

## 7. Голос

**Лучший вариант:** записать фразы голосом мамы или дяди. Знакомый голос сильно увеличивает вовлечение малышей.

- Около 60–80 коротких фраз; список в `assets/audio/phrases.csv` (`id;текст`).
- Имена детей записываются отдельными файлами и склеиваются: «Сейчас строит» + «Амир».
- Формат: mp3 или ogg, моно, 64–96 kbps.

**Запасной вариант:** заранее сгенерированные TTS-файлы. Не использовать Web Speech API в реальном времени: на планшетах русский голос может отсутствовать или звучать плохо.

**Если файла нет:** игра не падает, звук пропускается, в консоль пишется `console.warn`.

### Модель данных: контент — это данные

Новый этап или задание добавляется в `stages.ts`, без нового кода сцен.

```ts
type Level = 'toddler' | 'preschool' | 'older';
type TaskType = 'tap' | 'drag' | 'choose' | 'count' | 'pattern' | 'mixColor';

interface TaskDef {
  type: TaskType;
  voicePrompt: string; // id фразы из phrases.csv
  params: Record<string, unknown>; // например { target: 5 } или { options: ['crane','mixer','truck'] }
}

interface StepDef {
  id: string; // 'walls1_step3'
  stageId: number; // 1..12
  housePart: string; // какая деталь появится в доме после шага
  byLevel: Record<Level, TaskDef>; // для каждого уровня своё задание (обязательно все три)
}

interface SaveState {
  version: number;
  completedSteps: string[];
  turnsByPlayer: Record<string, number>;
  nextPlayerId: string;
  settings: { musicOn: boolean; turnLimit: number | null };
}
```

## 10. Как понять, что игра работает

- Малыш тапает и смеётся, не застревает.
- 3-летний сам доводит задание до конца (с подсказкой или без).
- 5-летний просит «ещё ход» и объясняет младшим, что делать.
- Очередь не превращается в ссору (или родитель решает за секунду).
- Дети сами возвращаются к игре на следующий день.
