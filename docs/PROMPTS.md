# Промпты для Claude Code — по шагам

Вставляйте по одному в `claude` в корне репозитория. Каждый промпт = один пункт плана.
После каждого шага: `pnpm dev --host`, откройте с планшета по IP компьютера и проверьте руками.

---

## 0. Каркас проекта

```
Прочитай CLAUDE.md и docs/GAME_SPEC.md. Создай каркас проекта: Vite + TypeScript (strict) + Phaser 4,
структуру папок из GAME_SPEC §8, скрипты pnpm (dev, build, test, test:e2e, lint), Vitest и Playwright.
Пока без игровой логики: BootScene показывает фон неба и надпись «Наш дом». Landscape, Scale.FIT 1600×900,
запрет pinch-zoom, выделения и контекстного меню. Сначала покажи план, потом делай.
```

## 1. Игроки и очередь (v0.1)

```
Реализуй players.json, TurnManager и PlayerSelectScene по GAME_SPEC §2–3: три большие круглые
кнопки с аватаром и именем, следующий игрок пульсирует, можно выбрать любого, звёзды-счётчик
под каждым. Аватары пока цветные круги с первой буквой имени. Покрой TurnManager тестами Vitest.
```

## 2. Движок заданий и подсказки (v0.1)

```
Реализуй модель данных из GAME_SPEC §8 (TaskDef, StepDef, SaveState), TaskScene и три типа заданий:
TapTask, DragTask, ChooseTask, плюс HintManager (2 ошибки → подсветка, 3 → автопомощь).
Задание выбирается по уровню текущего игрока. Соблюдай жёсткие правила из CLAUDE.md.
```

## 3. Дом и этапы 1–3 (v0.1)

```
Реализуй house.config.json и HouseScene: вид сбоку, дом в разрезе, 2 этажа, участок с забором.
Детали дома появляются по completedSteps. Добавь в stages.ts этапы 1–3 (участок, фундамент,
стены 1 этажа) с заданиями для всех трёх уровней по таблице GAME_SPEC §5. Графику рисуй простыми
SVG-формами. Подключи SaveManager (localStorage, version, миграции).
```

## 4. Озвучка-заглушки (v0.1)

```
Реализуй AudioManager и assets/audio/phrases.csv со всеми фразами для этапов 1–3 и экрана выбора.
Имя игрока склеивается из отдельного файла. Если файла нет: пропуск и console.warn.
Сгенерируй список фраз, которые нужно будет записать, отдельным файлом docs/RECORDING_LIST.md.
```

> ✅ Здесь v0.1 готова: **дайте детям поиграть** и запишите, что им понравилось и где застряли.
